# Recipe App📖

Консольное приложение на C# для организации личной кулинарной книги. Проект демонстрирует навыки работы с объектно-ориентированной архитектурой, обработкой данных и файловой системой.

---

## 🌟 Основные возможности

*   **Управление рецептами:** Полный цикл CRUD (Создание, Просмотр, Поиск, Добавление).
*   **Интеграция медиа:** Возможность прикреплять пути к фотографиям блюд для визуализации рецепта.
*   **Умный поиск:** Быстрый поиск нужного рецепта по названию или ингредиентам.
*   **Интуитивный интерфейс:** Удобное консольное меню с понятной навигацией и подсказками для пользователя.
*   **Cистема категорий** Разделение рецептов по категориям.

## 🛡️ Безопасность и архитектура данных

При разработке особое внимание уделялось надежности хранения и обработки информации:

1.  **Валидация ввода:**
    *   Проверка на пустые поля при добавлении рецепта.
    *   Контроль корректности путей к файлам (фотографиям).
2.  **Хранение данных:** Реализована логика связывания текстового описания рецепта с метаданными изображений, что позволяет хранить библиотеку структурировано.

## 🛠️ Технологический стек

*   **Язык:** C# (.NET Core / .NET 6+)
*   **Архитектура:** OOP (Encapsulation, Inheritance, Polymorphism).
*   **Data Management:** .Framework 
*   **Database:** База данных с оптимизированной структурой таблиц под рецепты и медиа-файлы.

## 🏗️ Логика реализации

*   **Классовая структура:** Созданы отдельные модели для рецептов (`Recipe`), ингредиентов и связей с фото.
*   **Data Access Layer (DAL):** Выделенный слой для работы с базой данных, обеспечивающий чистоту основного кода.
*   **Обработка исключений:** Реализованы блоки `try-catch` для предотвращения вылета приложения при ошибках доступа к файлам или БД.
